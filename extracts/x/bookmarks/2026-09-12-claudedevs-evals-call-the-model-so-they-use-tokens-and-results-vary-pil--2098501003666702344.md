# Claude Code plugin evals

**@ClaudeDevs** · [2098501003666702344](https://x.com/ClaudeDevs/status/2098501003666702344) · `announcement`

## Resumo
Anúncio do recurso de evals de plugins no Claude Code: evals consomem tokens e têm resultados variáveis, por isso pilotar com `--runs 1` antes da execução completa. Como hooks e servidores MCP de plugins rodam como o próprio usuário, deve-se avaliar apenas plugins confiáveis; disponível via `claude update`.
