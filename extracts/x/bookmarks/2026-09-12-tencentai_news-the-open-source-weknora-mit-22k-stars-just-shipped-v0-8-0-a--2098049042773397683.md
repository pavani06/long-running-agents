# WeKnora v0.8.0: agentic RAG

**@TencentAI_News** · [2098049042773397683](https://x.com/TencentAI_News/status/2098049042773397683) · `announcement`

## Resumo
WeKnora, plataforma open-source de agentes de conhecimento da Tencent (MIT, 22k stars), lançou a v0.8.0 evoluindo de RAG para agentic RAG com memória persistente entre sessões e execução em sandbox seguro. Vale salvar como referência de arquitetura de memória e agentes sobre base de conhecimento.

## Pontos-chave
- Release v0.8.0 da WeKnora: código aberto sob licença MIT, ~22k stars no GitHub
- Movimento de RAG tradicional para agentic RAG: agente de conhecimento que se auto-lembrar (self-remembering)
- Memória cross-session tipada em cinco categorias: profile, preference, fact, task e interest — taxonomia útil para design de memória de agentes
- Execução sandboxed para segurança nas ações do agente sobre o conhecimento
