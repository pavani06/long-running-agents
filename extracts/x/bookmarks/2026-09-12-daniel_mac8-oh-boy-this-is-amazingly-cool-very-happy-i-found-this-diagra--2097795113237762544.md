## Resumo
Skill 'diagram-design' instalável em Codex e Claude Code capaz de gerar 39 tipos diferentes de diagramas com boa qualidade visual. Vale salvar como recurso pronto para melhorar documentação técnica gerada por agentes.

- Gera 39 tipos distintos de diagramas, com foco explícito em qualidade ('actually good')
- Funciona tanto no Codex quanto no Claude Code como skill plugável
- Aplicável a documentação técnica e comunicação de arquitetura em fluxos de agentic coding
