## Resumo
Time do Claude Code removeu ~80% do system prompt para os modelos mais novos e compartilhou lições sobre como escrever system prompts, skills e CLAUDE.MDs eficazes. Referência direta para context engineering em agentes de coding.

## Pontos-chave
- ~80% do system prompt do Claude Code foi removido para os modelos mais recentes
- Modelos novos exigem prompts menos prescritivos — muito do prompt antigo virou redundante ou ruído
- Lições se aplicam também a skills e arquivos CLAUDE.md (contexto por projeto), não só ao prompt central
