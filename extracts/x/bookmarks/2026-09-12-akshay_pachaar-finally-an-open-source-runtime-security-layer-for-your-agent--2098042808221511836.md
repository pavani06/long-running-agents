# runtime security layer para agentes

**@akshay_pachaar** · [2098042808221511836](https://x.com/akshay_pachaar/status/2098042808221511836) · `announcement`

## Resumo
Anúncio de uma camada open-source de segurança em runtime para harnesses de agentes, que dá visibilidade sobre o que o agente realmente executou. Endereça o problema de reconstruir ações do agente a partir de logs dispersos após falhas em produção.

## Pontos-chave
- Agentes de IA podem chamar tools, executar comandos shell, modificar arquivos e interagir com sistemas de produção
- Quando algo dá errado, times precisam reconstruir manualmente o que o agente fez a partir de fontes dispersas
- A solução proposta é uma camada de segurança/observabilidade de runtime open-source integrada ao harness do agente
