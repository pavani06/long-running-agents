# Skill ADHD-friendly para coding agents

**@trending_repos** · [2099469831879737663](https://x.com/trending_repos/status/2099469831879737663) · `tool`

## Resumo
Repositório em alta (i-have-adhd) que é um skill/plugin para Claude Code forçando respostas diretas do agente de código: ação primeiro, passos numerados e zero enrolação. Vale salvar como exemplo prático e popular de engenharia de estilo/formato de saída para agentes.

## Pontos-chave
- Define 10 regras em SKILL.md: começar pela próxima ação, numerar tarefas multi-passo, terminar com um próximo passo concreto, suprimir tangentes, reafirmar o estado a cada turno, estimativas de tempo em minutos, erros sem drama, listas limitadas a 5 itens, e sem preâmbulo/recap/fechamentos tipo 'Hope this helps!'
- Instalação como plugin do Claude Code via marketplace; para customizar, faz-se fork, edita skills/i-have-adhd/SKILL.md e troca-se a cópia com plugin uninstall/marketplace remove/add/install
- Loosely baseado em 'The Adult ADHD Tool Kit' (J. Russell Ramsay e Anthony L. Rostain), adaptado para como um LLM deve responder, não para organização pessoal humana
- Popularidade significativa: 16.740 estrelas na semana e 44.965 no total, indicando demanda real por saídas de agentes menos verbosas
