# AIF e ontologia para LLMs

**@1amageek** · [2078942607863148919](https://x.com/1amageek/status/2078942607863148919) · `opinion`

## Resumo
@1amageek recomenda estudar AIF depois de aprender Ontologia, descrevendo-o como 'notas para discussão rigorosa' e um formato para transmitir entendimento a LLMs sem ambiguidade.

## Pontos-chave
- Sequência de estudo sugerida: dominar Ontologia primeiro, depois avançar para AIF.
- AIF é difícil de definir em uma palavra; o autor o caracteriza como anotações para discussão rigorosa.
- Propósito prático do AIF: servir como formato para passar compreensão a LLMs sem mal-entendidos.
