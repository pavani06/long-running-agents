# Data Agent Kit no IDE

**@Marwan_3atef** · [2097976275373531523](https://x.com/Marwan_3atef/status/2097976275373531523) · `announcement`

## Resumo
Google Cloud integrou o Data Agent Kit às IDEs via MCP, com conectores para BigQuery, AlloyDB, Cloud SQL, Spark e Spanner, para eliminar o copy-paste de SQL entre consoles. Vale salvar como referência de tooling agêntico aplicado a data platform.

## Pontos-chave
- MCP disponível para BigQuery, AlloyDB, Cloud SQL, Spark e Spanner
- Skills de agente para ELT, checagem de drift de dados e pipelines
- Compatível com Cursor, Claude Code, Codex e VS Code
- Proposta central: o agente opera diretamente sobre o stack de dados em vez de alternar entre consoles
