# Web guidance para agentes

**@ChromiumDev** · [2100291127005856239](https://x.com/ChromiumDev/status/2100291127005856239) · `announcement`

## Resumo
O time do Chrome anunciou que o Modern Web Guidance atingiu 10 mil instalações; o pacote de skills leva expertise da plataforma web direto para workflows de agentes, podendo ser combinado com o Chrome DevTools for agents para auditar performance e corrigir código automaticamente.

## Pontos-chave
- Modern Web Guidance ultrapassou 10.000 instalações, indicando adoção rápida pela comunidade de desenvolvimento com agentes
- O pacote funciona como skills que injetam conhecimento da plataforma web (padrões, boas práticas) em workflows de agentes
- Pode ser pareado com Chrome DevTools for agents para auditar performance de páginas e aplicar correções de código automaticamente
