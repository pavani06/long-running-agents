# Lançamento do modelo Jev

**@manthanguptaa** · [2100466984605417923](https://x.com/manthanguptaa/status/2100466984605417923) · `opinion`

## Resumo
Manthan Gupta analisa o lançamento do modelo Jev, que questiona por que LLMs autorregressivos são usados como 'if statements' caras dentro de software. O argumento central é que gerar tokens um a um é computacionalmente exagerado para tarefas de decisão e roteamento.

## Pontos-chave
- Jev questiona o paradigma de usar LLMs autorregressivos como lógica condicional (if statements) excessivamente cara dentro de aplicações
- LLMs autorregressivos operam no esquema 'texto -> gerar tokens', o que desperdiça compute quando a tarefa exige apenas uma decisão/branching
- O tweet sugere espaço para arquiteturas de modelo desenhadas especificamente para decisões, e não para geração de texto
