# agents em código vs conhecimento

**@mattpocockuk** · [2096906181121818702](https://x.com/mattpocockuk/status/2096906181121818702) · `opinion`

## Resumo
Matt Pocock argumenta que trabalho de conhecimento é muito mais difícil de automatizar com agentes do que software, porque o desenvolvimento tem verificação automática, documentação abundante e workspaces simples. Vale salvar como diagnóstico conciso de por que coding é o caso de uso mais maduro para agentes.

## Pontos-chave
- Desenvolvimento de software oferece loops de feedback automatizados de alta qualidade (types, tests) que permitem ao agente se autocorrigir
- Documentação é gratuita, bem organizada e pesquisável na web, reduzindo o custo de coleta de contexto pelo agente
- Workspaces de código são simples de usar (repo, terminal, editor), facilitando a execução e iteração do agente
- Trabalho de conhecimento em geral carece dessas propriedades: feedback difuso, documentação fragmentada/privada e ambientes de trabalho bagunçados
