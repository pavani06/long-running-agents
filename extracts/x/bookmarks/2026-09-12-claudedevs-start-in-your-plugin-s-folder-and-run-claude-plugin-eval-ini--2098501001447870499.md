# evals para plugins Claude

**@ClaudeDevs** · [2098501001447870499](https://x.com/ClaudeDevs/status/2098501001447870499) · `announcement`

## Resumo
Comando `claude plugin eval init` bootstrapa uma suíte de evals para plugins do Claude: o usuário define exemplos de saída boa/ruim com prompts reais, e o Claude redige casos de teste e checagens, pilota a suíte e estima o custo de uma execução completa. Vale salvar como referência de workflow oficial para criar evals de agentes/plugins com estimativa de custo.
