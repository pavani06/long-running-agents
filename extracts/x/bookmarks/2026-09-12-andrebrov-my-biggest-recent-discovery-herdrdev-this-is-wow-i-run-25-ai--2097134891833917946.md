# Console para orquestrar agentes de código

**@andrebrov** · [2097134891833917946](https://x.com/andrebrov/status/2097134891833917946) · `thread`

## Resumo
Apresenta o herdr (@herdrdev), um console de terminal que centraliza ~25 agentes de coding AI distribuídos em 5 harnesses (Claude Code, Codex, opencode/GLM, Grok, agy), cada um com papel definido (coder, reviewer), tratando o conjunto como um time e não um chatroom. Vale salvar como descoberta de ferramenta para orquestração multi-agente de código.

## Pontos-chave
- herdr unifica ~25 agentes de código em um único terminal, evitando alternar entre várias interfaces de chat
- Suporta 5 harnesses: Claude Code, Codex, opencode/GLM, Grok e agy
- Cada agente recebe um papel específico (coder, reviewer), estruturando o ensemble como uma equipe com divisão de trabalho
- Thread (visível apenas o tweet inicial) descreve o workflow do autor; conteúdo truncado — explorar o resto do thread e a ferramenta
