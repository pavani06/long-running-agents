# Agente que converte aulas em cheat sheets

**@tetsuoai** · [2100109861602357730](https://x.com/tetsuoai/status/2100109861602357730) · `tool`

## Resumo
Template de bot no Grok que recebe a URL de uma aula no YouTube e gera um PDF denso pronto para prova, com matemática tipografada em Typst, diagramas e fórmulas verificadas via SymPy. Vale salvar como padrão de pipeline agêntico (URL → documento) com etapa de verificação automática.

## Pontos-chave
- Pipeline simples de entrada/saída: URL de aula no YouTube entra, PDF cheat sheet sai
- Usa Typst para matemática tipografada de verdade e diagramas no PDF
- Fórmulas são checadas programaticamente com SymPy, adicionando uma camada de verificação à geração
- Posicionado como artefato pronto para estudo/exames (exam-ready), não apenas resumo raso
