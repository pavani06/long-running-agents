# Metodologia de avaliação de skills (OpenAI)

**@snwiki238337** · [2099052462653002157](https://x.com/snwiki238337/status/2099052462653002157) · `resource`

## Resumo
OpenAI publicou uma metodologia para avaliar a eficácia de skills de agentes, com princípio central de definir sucesso antes de escrever o skill; o tweet também aponta o repo agent-skills-eval como alternativa não oficial com filosofia similar. Vale salvar como referência para quem constrói skills e precisa de evals estruturados.

## Pontos-chave
- Princípio central: definir o sucesso primeiro, só depois escrever o skill
- Checkpoints divididos em 4 dimensões, incluindo Outcome (a tarefa foi concluída?) e Process (o skill chamou os passos/ferramentas esperados?)
- Repo GitHub 'agent-skills-eval' segue filosofia muito próxima, mas é mantido individualmente (não oficial)
