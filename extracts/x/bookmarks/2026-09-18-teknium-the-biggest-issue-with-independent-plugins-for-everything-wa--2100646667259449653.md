# Plugins API discoverability

**@Teknium** · [2100646667259449653](https://x.com/Teknium/status/2100646667259449653) · `opinion`

## Resumo
Teknium argumenta que o gargalo dos plugins independentes nunca foi a API, mas a discoverability, que agora foi resolvida. Insight de design relevante para ecossistemas de tooling de agentes: capacidade técnica já existia (tool providers, memory systems), faltava mecanismo de descoberta.

## Pontos-chave
- O maior problema de um ecossistema de plugins independentes era a discoverability, não a capacidade da API
- A superfície da Plugins API já era forte o suficiente para suportar tool providers, sistemas de memória e outros casos de uso
- Com um mecanismo de discoverability, a barreira prática para adoção de plugins cai drasticamente
