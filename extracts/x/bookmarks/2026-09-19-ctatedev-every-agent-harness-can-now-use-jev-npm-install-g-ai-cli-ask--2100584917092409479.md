# Jev CLI para agent harnesses

**@ctatedev** · [2100584917092409479](https://x.com/ctatedev/status/2100584917092409479) · `announcement`

## Resumo
Anúncio de que o Jev agora pode ser usado por qualquer agent harness via npm global (ai-cli), permitindo que agentes façam perguntas sim/não, escolham entre opções e pontuem itens segundo critérios definidos.

## Pontos-chave
- Instalação global simples via `npm install -g ai-cli`, tornando a ferramenta disponível para qualquer harness de agente
- Suporta perguntas binárias (yes/no) para interação humano-no-loopo durante execução do agente
- Permite seleção entre múltiplas opções e pontuação de alternativas contra critérios definidos pelo usuário
