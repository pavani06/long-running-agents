# Hermes Agent Plugin Catalog

**@NousResearch** · [2100266421020152114](https://x.com/NousResearch/status/2100266421020152114) · `announcement`

## Resumo
NousResearch lançou um catálogo de plugins para o Hermes Agent com 4 plugins oficiais e 96 da comunidade, todos revisados pela equipe e com SHA fixado (SHA-pinned). Instalação via Hermes Desktop ou comando CLI; novos plugins adicionados regularmente.

## Pontos-chave
- Catálogo inicial com 4 plugins oficiais e 96 da comunidade, cobrindo mods de desktop, novas plataformas, navegação e ferramentas especializadas
- Todo plugin da comunidade passa por revisão da equipe da NousResearch antes de entrar no catálogo
- Plugins são SHA-pinned, garantindo integridade/segurança da cadeia de suprimentos na instalação
- Instalação pode ser feita revisando dentro do Hermes Desktop ou copiando o comando CLI; catálogo será expandido continuamente
