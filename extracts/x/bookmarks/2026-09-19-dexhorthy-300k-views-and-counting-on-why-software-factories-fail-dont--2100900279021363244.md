# software factories e coding agents

**@dexhorthy** · [2100900279021363244](https://x.com/dexhorthy/status/2100900279021363244) · `resource`

## Resumo
Deep dive em vídeo de Dex Horthy sobre por que 'fábricas de software' com agentes de código falham e como desenhá-las corretamente. Defende que humanos continuem lendo o código gerado por agentes, mesmo em pipelines automatizados.

## Pontos-chave
- Fábricas de software (pipelines de geração com agentes) falham por motivos identificáveis de design, não por limitação dos modelos
- Mesmo com coding agents, ler e revisar o código permanece essencial — automação total sem supervisão é armadilha
- Apresenta princípios concretos para desenhar uma software factory que funcione em produção
