# Data agent no ChatGPT Work

**@ChatGPT** · [2098065296968011853](https://x.com/ChatGPT/status/2098065296968011853) · `announcement`

## Resumo
OpenAI anuncia um Data agent no ChatGPT Work que converte dados corporativos em respostas, dashboards interativos e ações via linguagem natural. Ativação via Data Plugin conectado às fontes de dados da empresa.

## Pontos-chave
- Novo agente de dados embutido no ChatGPT Work gera respostas, dashboards interativos e ações a partir dos dados da empresa apenas com pedidos em linguagem natural
- Setup é feito adicionando o Data Plugin e conectando as fontes de dados e contexto corporativo
- Move análise de dados para dentro do fluxo de trabalho do ChatGPT, sem depender de ferramentas de BI separadas
