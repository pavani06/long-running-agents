# Catálogo de plugins do Hermes

**@Teknium** · [2100646469015609779](https://x.com/Teknium/status/2100646469015609779) · `announcement`

## Resumo
Teknium anuncia que as integrações do Hermes viraram plugins distribuídos via catálogo, eliminando a necessidade de empacotá-las em toda instalação. Vale salvar como decisão de arquitetura para reduzir carga de manutenção e desacoplar o core do produto.

## Pontos-chave
- Integrações antes bundladas no Hermes foram migradas para o formato de plugins
- Existência de um catálogo de plugins permite desacoplar o packaging de cada install
- Reduz a carga de manutenção da equipe, que passa a focar apenas no que importa
