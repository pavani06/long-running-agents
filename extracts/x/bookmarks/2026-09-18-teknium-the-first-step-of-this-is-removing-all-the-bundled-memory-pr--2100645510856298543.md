# Desacoplamento de provedores de memória

**@Teknium** · [2100645510856298543](https://x.com/Teknium/status/2100645510856298543) · `announcement`

## Resumo
Anúncio do Teknium de remover todos os provedores de Memory acoplados ao core de um projeto de memória de agentes, migrando para um modelo de plugins mantidos pelos próprios criadores. Sinaliza arquitetura modular com marketplace, similar à abordagem do Model Context Protocol.

## Pontos-chave
- Todos os provedores de Memory bundled serão removidos da base do projeto
- Cada provedor passará a ser mantido pelo seu criador, no repositório da própria organização
- A distribuição ocorrerá via plugins market, centralizando descoberta mas descentralizando manutenção
