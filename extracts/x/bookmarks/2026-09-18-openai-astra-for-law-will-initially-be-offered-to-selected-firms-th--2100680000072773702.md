# OpenAI Astra for Law

**@OpenAI** · [2100680000072773702](https://x.com/OpenAI/status/2100680000072773702) · `announcement`

## Resumo
OpenAI anunciou o Astra for Law, oferta verticalizada para jurídico, inicialmente para firmas selecionadas via Trusted Access no ChatGPT e Codex, com API em breve. Vale salvar como sinal da estratégia da OpenAI de produtos verticais com configuração de domínio mantida pela própria OpenAI.

## Pontos-chave
- Rollout inicial restrito: firmas de advocacia selecionadas via Trusted Access no ChatGPT e Codex
- Acesso via API será disponibilizado em breve, abrindo para builders integrarem nos próprios produtos
- OpenAI manterá a configuração jurídica (compliance/domínio), desobrigando builders de gerenciá-la
- Indica movimento da OpenAI em produtos verticais especializados por setor em vez de apenas modelos genéricos
