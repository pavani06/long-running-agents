# Claude plugin evaluation CLI

**@ClaudeDevs** · [2098501002588823568](https://x.com/ClaudeDevs/status/2098501002588823568) · `tool`

## Resumo
Como rodar avaliações de plugins do Claude via `claude plugin eval`, comparando o score de cada caso com e sem o plugin ativo. Vale salvar como referência do fluxo oficial de evals para plugins, com saída no terminal, relatório HTML e publicação opcional como artifact privado.

## Pontos-chave
- O comando `claude plugin eval` pontua cada caso de teste duas vezes: com e sem o plugin instalado, permitindo medir o impacto real do plugin
- Os scores aparecem diretamente no terminal durante a execução
- É gerado um relatório HTML com o detalhamento completo dos resultados por caso
- Se a conta suportar, o relatório também é publicado como um artifact privado
