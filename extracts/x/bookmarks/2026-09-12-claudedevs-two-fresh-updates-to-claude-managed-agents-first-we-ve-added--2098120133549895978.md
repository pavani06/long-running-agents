# Session viewer no ant CLI

**@ClaudeDevs** · [2098120133549895978](https://x.com/ClaudeDevs/status/2098120133549895978) · `announcement`

## Resumo
Anúncio de atualização do Claude Managed Agents: novo session viewer no ant CLI, permitindo conectar o terminal a uma sessão em execução via `ant beta:sessions connect` ou abrir uma web UI via `--web` servida do localhost. Relevante para observabilidade e depuração de sessões de agentes em produção.

## Pontos-chave
- Session viewer foi adicionado ao ant CLI como parte dos updates do Claude Managed Agents
- `ant beta:sessions connect` anexa o terminal a uma sessão de agente em execução
- Flag `--web` abre uma interface web servida de localhost para inspecionar a sessão
- Facilita observabilidade e debugging de agentes gerenciados sem interromper a execução
