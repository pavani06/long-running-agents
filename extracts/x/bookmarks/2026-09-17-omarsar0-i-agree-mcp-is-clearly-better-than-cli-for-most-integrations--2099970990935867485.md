# MCP versus CLI em harnesses

**@omarsar0** · [2099970990935867485](https://x.com/omarsar0/status/2099970990935867485) · `opinion`

## Resumo
Opinião de Omar Sarra de que MCP é claramente superior a CLI para a maioria das integrações com agentes, e que modelos de fronteira estão cada vez melhores em usá-lo. Vale salvar como endosso prático: harnesses customizados devem usar MCP para todas as ferramentas externas.

## Pontos-chave
- MCP supera CLI na maioria das integrações de agentes, percepção que se mantém ao longo do tempo
- Modelos de fronteira continuam melhorando em usar ferramentas MCP
- Recomendação direta: quem constrói harnesses customizados deve usar MCP tools
- O autor usa MCP para todas as ferramentas externas em seus meta harnesses
