# Sistemas que se auto-promptam em agentes

**@AnatoliKopadze** · [2080286550005358977](https://x.com/AnatoliKopadze/status/2080286550005358977) · `resource`

## Resumo
Tweet promove uma palestra de ~45 min de uma engenheira da Anthropic sobre construir agentes como sistemas que se autogerenciam — com memória, autocorreção de erros e melhoria incremental a cada execução — em vez de depender de prompting manual. Vale salvar como ponteiro para o vídeo/talk (links encurtados; conteúdo do artigo não disponível).

## Pontos-chave
- Mentalidade-chave: o trabalho não é escrever prompts para o Claude, mas construir um sistema/harness que se auto-prompta
- Agentes projetados para memorizar contexto entre execuções (memória persistente)
- Capacidade de detectar e corrigir os próprios erros durante o loop do agente
- Melhoria contínua: cada execução deixa o sistema mais inteligente (aprendizado operacional)
