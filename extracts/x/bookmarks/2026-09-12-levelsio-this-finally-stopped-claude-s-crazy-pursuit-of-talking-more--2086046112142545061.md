# Controlar estilo do Claude via memória

**@levelsio** · [2086046112142545061](https://x.com/levelsio/status/2086046112142545061) · `opinion`

## Resumo
Pieter Levels relata que parou a deriva do Claude para respostas cada vez mais ininteligíveis/verbosas salvando na memória a instrução de sempre usar ASD-STE100 Simplified Technical English. É um truque concreto de constraint persistente de estilo aplicável a qualquer chat com memória.

## Pontos-chave
- O prompt usado foi: 'Save in memory to always use ASD-STE100 Simplified Technical English when you talk to me', tornando a restrição permanente entre sessões
- ASD-STE100 é um inglês técnico controlado (origem aeroespacial) que limita vocabulário e estrutura de frases, forçando respostas mais simples e diretas
- Demonstra que instruções salvas em memória servem como mecanismo de governança de estilo para conter a deriva de verbosidade/jargão dos LLMs ao longo do tempo
