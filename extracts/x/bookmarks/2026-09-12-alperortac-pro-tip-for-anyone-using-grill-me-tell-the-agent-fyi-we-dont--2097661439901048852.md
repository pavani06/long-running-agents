# dica anti-overengineering para agentes

**@alperortac** · [2097661439901048852](https://x.com/alperortac/status/2097661439901048852) · `opinion`

## Resumo
Dica prática para usar o comando /grill-me: dizer ao agente que 'não queremos overengineer' deixa o resto da sessão com decisões mais simples, sem etapas desnecessárias. Vale salvar como padrão de prompt para conter a tendência de agentes de complicar soluções.
