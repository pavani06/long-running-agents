# Lançamento do Kimi Code CLI

**@zodchiii** · [2078222648539271430](https://x.com/zodchiii/status/2078222648539271430) · `announcement`

## Resumo
Moonshot lançou o Kimi Code CLI, um clone open-source do Claude Code sob licença MIT e gratuito, mantido pelo mesmo lab que lançou o Kimi K3. Diferenciais citados incluem aceitar gravações de tela como input do chat e modos coder/explore embutidos.

## Pontos-chave
- Open source com licença MIT e gratuito, posicionando-se como alternativa direta ao Claude Code da Anthropic
- Aceita dropar uma gravação de tela no chat como entrada, algo que o Claude Code não faz nativamente
- Traz modos embutidos distintos (coder e explore) para diferentes fluxos de trabalho
- Mantido pela Moonshot, o mesmo laboratório que lançou o modelo K3 recentemente
