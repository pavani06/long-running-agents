# Fluxo desenho-para-código com Codex

**@alex_frantic** · [2080776965070496115](https://x.com/alex_frantic/status/2080776965070496115) · `resource`

## Resumo
Tip prático para usar Codex: desenhar um grafo/workflow em qualquer ferramenta (até no papel), enviar a imagem e pedir um script em 'code mode' que implemente e execute o fluxo com os inputs dados. O autor afirma que não há passo 3 — funciona direto.

## Pontos-chave
- Qualquer diagrama, inclusive desenhado à mão, serve como especificação visual: o Codex converte o grafo em código executável.
- O prompt reduz-se a uma instrução única: 'write a code mode script that implements this workflow, run it with <inputs>'.
- A ausência de etapa de iteração/correção ('it just works') sugere forte capacidade multimodal de visão-para-código no fluxo com 5.6 Sol.
- Abre caminho para especificar agentes/workflows graficamente em vez de escrever código ou specs textuais manualmente.
