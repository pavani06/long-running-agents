# MCP deferred tools e progressive disclosure

**@trq212** · [2099959418909851997](https://x.com/trq212/status/2099959418909851997) · `opinion`

## Resumo
Explica que deferred tools no MCP funcionam como progressive disclosure: o modelo precisa chamar a ferramenta primeiro para descobrir todos os parâmetros, assim como um CLI só revela suas opções quando invocado.

## Pontos-chave
- Deferred tools é essencialmente progressive disclosure aplicado a MCPs, evitando expor toda a definição de ferramentas de antemão
- Analogia com CLIs: assim como um comando só revela seus parâmetros quando chamado, a ferramenta MCP entrega seus params sob demanda
- O padrão mantém o comportamento de descoberta em duas etapas (chamar primeiro, receber definição completa depois) que já é natural em interfaces de linha de comando
