# Projects no Claude Code

**@ClaudeDevs** · [2100633571543367691](https://x.com/ClaudeDevs/status/2100633571543367691) · `announcement`

## Resumo
Anthropic anuncia Projects no Claude Code (desktop e web): uma única conversa em que o próprio Claude divide o trabalho em threads, executa-as como sessões paralelas na nuvem, compartilha contexto entre elas e continua rodando após o usuário sair. Disponível em beta para usuários selecionados.

## Pontos-chave
- Um projeto é uma conversa única; o Claude particiona o trabalho em threads automaticamente
- Threads rodam como sessões paralelas na nuvem (cloud sessions)
- Contexto é passado entre as sessões, mantendo coerência do trabalho
- Execução continua em background mesmo quando o usuário fecha/sai
- Lançamento em beta para um grupo selecionado de usuários
