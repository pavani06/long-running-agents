# GitHub Spec Kit e spec-driven development

**@txbrraa** · [2097955506891469272](https://x.com/txbrraa/status/2097955506891469272) · `announcement`

## Resumo
GitHub lançou o Spec Kit, toolkit open source que obriga agentes de IA a produzirem uma especificação antes de gerar código, atacando o problema do 'vibe coding'. Já ultrapassou 126 mil estrelas no GitHub pouco após o lançamento.

## Pontos-chave
- Em vez de prompts vagos, o agente é forçado a criar uma especificação explícita antes de codar, reduzindo o risco de quebrar o projeto.
- Posiciona-se como solução direta ao 'vibe coding': substitui esperança e tentativa-e-erro por direção estruturada para o agente.
- Adoção rápida e alta visibilidade: mais de 126 mil estrelas em pouco tempo após o lançamento.
