# Grok Bot resource hub

**@aiedge_** · [2097897898235269173](https://x.com/aiedge_/status/2097897898235269173) · `resource`

## Resumo
grokhub.io é um diretório comunitário de use cases, plugins, guias, templates e notícias para o Grok Bot, com distribuição via feed e endpoint MCP para bots assinarem em vez de fazerem scraping. Vale salvar como ponto de partida para descobrir setups prontos.

## Pontos-chave
- Funciona por submissões da comunidade (setups, guias, plugins, templates, notícias) que passam por aprovação antes de publicação.
- Distribuição via /feed diário e endpoint MCP (grokhub.io/mcp), permitindo que bots assinem o conteúdo em vez de extraí-lo por scraping.
- Inclui prompt sugerido: ler o feed diariamente e recomendar um novo use case ou plugin para experimentar.
- A filosofia do site é 'data, not instructions' — colar no bot só se quiser executar.
