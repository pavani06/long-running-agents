# MCP versus CLIs para agentes

**@RhysSullivan** · [2099970035137794430](https://x.com/RhysSullivan/status/2099970035137794430) · `opinion`

## Resumo
Opinião de que MCP supera CLIs como interface de ferramentas para agentes, com três vantagens concretas: catálogo de ferramentas indexável, dispensa de sandbox completo e autenticação consistente entre servidores.

## Pontos-chave
- Catálogo de ferramentas indexável permite que agentes escalem para um número ilimitado de ferramentas, algo inviável com CLIs ad hoc
- MCP não exige rodar um sandbox completo, reduzindo a infraestrutura necessária para expor ferramentas ao agente
- Autenticação é padronizada e consistente entre todos os MCPs, em vez de cada CLI inventar seu próprio esquema de auth
