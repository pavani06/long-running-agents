# Comparando interfaces de ferramentas para agentes

**@dair_ai** · [2099925472629150164](https://x.com/dair_ai/status/2099925472629150164) · `resource`

## Resumo
Paper da Microsoft ('Is Bash All You Need?') compara cinco interfaces de ferramentas para agentes corporativos, avaliando se bash basta como interface universal. Relevante para decisões de design sobre quais ferramentas dar a um agente em produção.

## Pontos-chave
- Avaliou cinco interfaces de ferramentas alternativas para agentes de empresa, incluindo bash como opção única/generic.
- Benchmarks usados: TheAgentCompany e APEX-Agents.
- Modelos avaliados: Claude Opus-4.8 e GPT-5.5, permitindo comparar sensibilidade das interfaces entre modelos.
