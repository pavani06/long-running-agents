# Wikipedia race como benchmark de agentes

**@CompleteSkeptic** · [2099925688925184171](https://x.com/CompleteSkeptic/status/2099925688925184171) · `opinion`

## Resumo
Um jogo de correr de uma página da Wikipedia a outra usando apenas links expõe um espaço de decisão de centenas a milhares de opções por passo. Vale salvar porque mostra que o desempenho depende não só de inteligência-por-segundo, mas do benefício composto de não alucinar escolhas em espaços de ação de alta cardinalidade.

## Pontos-chave
- A tarefa é navegar da página inicial à página alvo usando exclusivamente links internos da Wikipedia.
- O desafio central é a alta cardinalidade: cada passo exige escolher entre centenas ou milhares de links válidos.
- O jogo mede inteligência-por-segundo do agente, não apenas qualidade estática das respostas.
- Um único link alucinado (inexistente) invalida o caminho, então não alucinar gera benefício composto ao longo da trajetória — espelhando loops de agente reais com muitas ferramentas/ações disponíveis.
