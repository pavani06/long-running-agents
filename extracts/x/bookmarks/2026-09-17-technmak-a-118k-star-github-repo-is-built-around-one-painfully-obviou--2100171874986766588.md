# Grafo de conhecimento do codebase

**@techNmak** · [2100171874986766588](https://x.com/techNmak/status/2100171874986766588) · `tool`

## Resumo
Graphify converte um projeto inteiro (funções, classes, arquivos, schemas SQL, infraestrutura, docs, PDFs) em um grafo de conhecimento consultável para que coding agents mapeiem a base uma única vez. A premissa: em vez de repetir greps a cada query, o agente consulta um mapa estrutural persistente do repositório.

## Pontos-chave
- Repositório com 118K estrelas no GitHub construído em torno de uma única ideia: agentes de código devem mapear a codebase uma vez, não buscar indefinidamente com grep
- A ferramenta extrai funções, classes, arquivos, schemas SQL, infraestrutura, documentação e até PDFs para um grafo de conhecimento unificado e consultável
- Substitui buscas repetidas por uma representação estrutural pré-computada, reduzindo loops de busca e desperdício de tokens do agente no entendimento do repositório
