# agente por projeto no Claude Code

**@trq212** · [2100638355872706571](https://x.com/trq212/status/2100638355872706571) · `announcement`

## Resumo
Anúncio de Projects, que traz a arquitetura do Claude Tag para o Claude Code: um agente por projeto gerencia memória e delega tarefas a subagentes, podendo agir de forma proativa e em schedules — alternativa mais organizada que acumular sessões soltas.

## Pontos-chave
- Um agente dedicado por projeto centraliza a gestão de memória/contexto em vez de dispersá-la em sessões
- O agente principal cria subagentes especializados para executar tarefas
- Suporta comportamento proativo e execução de tarefas agendadas (schedules)
- Proposta substitui a experiência fragmentada de múltiplas sessões do Claude Code
