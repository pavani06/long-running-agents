# Puro-2B open model release

**@openhonor** · [2093994412770566256](https://x.com/openhonor/status/2093994412770566256) · `announcement`

## Resumo
Puro-2B is released fully open beyond weights: technical report, final and intermediate checkpoints, training code and configs, data-processing framework, plus datasets and manifests. Valuable as a rare end-to-end reproducible training stack with paper (arXiv), code (Puro-Megatron) and assets on Hugging Face.
