# Lançamento do assistente iHermes

**@dankrieg** · [2100260309336535218](https://x.com/dankrieg/status/2100260309336535218) · `announcement`

## Resumo
Anúncio do iHermes, assistente pessoal de IA construído sobre o Hermes Agent, com memória via GBrain e interface direta pelo iMessage. Vale salvar como exemplo de produto de agente pessoal com memória persistente em canal de mensagens.

## Pontos-chave
- iHermes roda sobre o Hermes Agent, framework que a equipe já usava internamente para construir sistemas e automatizar trabalho
- Usa GBrain como sistema de memória do assistente
- A interface é o iMessage, eliminando atrito de adoção para usuários finais
- Motivação: expandir a valor obtido internamente com o Hermes para mais pessoas
