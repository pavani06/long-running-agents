# Codex Security CLI open-source

**@OpenAI** · [2082263717916586117](https://x.com/OpenAI/status/2082263717916586117) · `announcement`

## Resumo
OpenAI liberou silenciosamente um CLI de segurança open-source (descoberto primeiro no Hacker News) que escaneia repositórios, rastreia achados entre execuções, verifica correções e integra checagens de segurança ao CI/CD. Vale salvar como ferramenta prática para pipeline de código com agentes.

## Pontos-chave
- Escaneia repositórios em busca de problemas de segurança
- Rastreia findings de forma persistente entre execuções (track across runs)
- Verifica se correções de vulnerabilidades foram aplicadas
- Permite adicionar checagens de segurança automatizadas em pipelines CI/CD
- Release inicial, anunciado informalmente após descoberta no Hacker News
