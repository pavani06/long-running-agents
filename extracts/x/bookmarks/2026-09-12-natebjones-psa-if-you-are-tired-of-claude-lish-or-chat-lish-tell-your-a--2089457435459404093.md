# guia de estilo para IA

**@natebjones** · [2089457435459404093](https://x.com/natebjones/status/2089457435459404093) · `resource`

## Resumo
Recomendação de usar o Google Developer Docs Style Guide como base para uma skill que impõe estilo de escrita claro às respostas da IA, eliminando o tom característico de LLM ('Claude-lish'). Autor testou e considera superior ao ASD-STE100 Simplified Technical English.

## Pontos-chave
- Instruir a IA a ler o Google Developer Docs Style Guide e construir uma skill que o siga muda visivelmente o estilo de escrita das respostas
- O autor comparou com o ASD-STE100 (Simplified Technical English) e avaliou o guia do Google como melhor alternativa
- A abordagem funciona como correção prática para o 'Chat-lish' — o jargão e tom padronizados típicos de assistentes de IA
