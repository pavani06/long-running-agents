# HarnessDev: self-evolving agent harnesses

**@Sumanth_077** · [2098053941800100294](https://x.com/Sumanth_077/status/2098053941800100294) · `announcement`

## Resumo
ByteDance publicou o HarnessDev, benchmark que avalia se agentes de IA conseguem construir um harness executável do zero e melhorá-lo iterativamente usando feedback de execução. Inverte o paradigma dos benchmarks tradicionais, que mantêm o harness fixo e avaliam apenas o modelo.

## Pontos-chave
- HarnessDev testa a capacidade de agentes construírem um harness runnable a partir do zero, não apenas usá-lo
- O loop de melhoria usa feedback de execução para refinar o harness iterativamente (self-evolving)
- Critério central: a maioria dos benchmarks de agentes mantém o harness fixo e avalia só o modelo — este desloca o foco para a engenharia do harness pelo próprio agente
