# fundamentos para codar com agentes

**@mattpocockuk** · [2097611379763007870](https://x.com/mattpocockuk/status/2097611379763007870) · `opinion`

## Resumo
Matt Pocock lista 5 habilidades essenciais para a era do coding assistido por agentes: ler código, dominar terminal, usar guardrails (tipos, testes, linting) contra erros humanos/de agentes, estruturar a app para verificação melhor (deep modules, seams, adapters) e linguagem ubíqua de DDD. Vale salvar como checklist de prioridades de aprendizado quando o agente escreve o código e o humano revisa/direciona.
