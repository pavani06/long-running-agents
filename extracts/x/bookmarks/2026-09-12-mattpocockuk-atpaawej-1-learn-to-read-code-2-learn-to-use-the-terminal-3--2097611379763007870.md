# Habilidades fundamentais para devs na era de agentes

**@mattpocockuk** · [2097611379763007870](https://x.com/mattpocockuk/status/2097611379763007870) · `opinion`

## Resumo
Matt Pocuck lista 5 habilidades essenciais: ler código, usar o terminal, prevenir erros humanos/de agentes com types/tests/linting, estruturar a aplicação para melhorar testes/tipos, e a linguagem onipresente do DDD. Vale salvar como checklist de fundamentos para trabalhar bem com agentes de código.

## Pontos-chave
- Aprender a ler código é a habilidade nº 1
- Dominar o terminal como ferramenta base
- Times bons previnem erros humanos e de agentes com types, tests e linting
- Estruturar a aplicação (deep modules, seams, adapters) melhora a eficácia de testes e tipos
- Linguagem onipresente do DDD (ubiquitous language) como fundamento de comunicação/modelagem
