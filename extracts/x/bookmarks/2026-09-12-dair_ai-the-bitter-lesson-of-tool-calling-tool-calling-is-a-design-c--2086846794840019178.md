# Comparação de métodos de tool calling

**@dair_ai** · [2086846794840019178](https://x.com/dair_ai/status/2086846794840019178) · `announcement`

## Resumo
Pesquisa nova compara tool calling programático contra tool calling nativo em JSON em 14 modelos de linguagem de várias gerações, mostrando que a escolha de design/default do tool calling impacta silenciosamente a acurácia.

## Pontos-chave
- Tool calling é uma decisão de design, não um requisito fixo do modelo
- Os defaults de tool calling nativo em JSON podem estar custando acurácia de forma silenciosa
- A comparação abrange 14 LLMs ao longo de gerações distintas de modelos
- Alternativas programáticas ao JSON nativo podem ser mais confiáveis para chamadas de ferramentas
