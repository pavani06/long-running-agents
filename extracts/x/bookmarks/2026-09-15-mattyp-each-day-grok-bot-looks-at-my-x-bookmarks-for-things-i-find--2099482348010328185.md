# pipeline automatizado de demos com agentes

**@mattyp** · [2099482348010328185](https://x.com/mattyp/status/2099482348010328185) · `announcement`

## Resumo
Descreve um loop autônomo em que o Grok monitora bookmarks do X diariamente, um Cursor Agent constrói demos, valida com screenshots/vídeo e abre branch em repo com preview deploys na Cloudflare, entregando um link toda manhã. Vale salvar como padrão replicável de orquestração de agentes ponta a ponta.

## Pontos-chave
- Grok Bot escaneia os bookmarks do X do autor para detectar temas de interesse
- Um Cursor Agent é instanciado automaticamente para construir um demo do item identificado
- O trabalho do agente é validado com screenshots e vídeo antes de prosseguir
- O pipeline corta uma branch em repo configurado com preview deploys da Cloudflare
- Um bot entrega o link do preview cada manhã, fechando o loop sem intervenção manual
