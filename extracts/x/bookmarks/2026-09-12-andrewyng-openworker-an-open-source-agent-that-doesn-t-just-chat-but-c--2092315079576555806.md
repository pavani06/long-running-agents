# OpenWorker: agente open source de tarefas locais

**@AndrewYNg** · [2092315079576555806](https://x.com/AndrewYNg/status/2092315079576555806) · `announcement`

## Resumo
Andrew Ng anuncia nova versão do OpenWorker, agente open source que executa tarefas (não apenas conversa) direto no laptop do usuário, agora com recursos voltados a fluxos de trabalho de segurança. Usuários da versão inicial adotaram a ferramenta principalmente para cibersegurança.

## Pontos-chave
- OpenWorker é um agente open source que completa tarefas no laptop local, em vez de apenas responder em chat
- A nova versão adiciona diversos recursos específicos para fluxos de trabalho de segurança
- Após o lançamento inicial, a base de usuários convergiu para casos de uso em cibersegurança
- O tweet sugere que atacantes já usam agentes/automação, motivando ferramentas defensivas (texto truncado)
