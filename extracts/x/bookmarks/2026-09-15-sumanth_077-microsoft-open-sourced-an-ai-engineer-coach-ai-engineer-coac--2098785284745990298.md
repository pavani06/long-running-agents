# Microsoft AI Engineer Coach

**@Sumanth_077** · [2098785284745990298](https://x.com/Sumanth_077/status/2098785284745990298) · `announcement`

## Resumo
A Microsoft open-sourcou o AI Engineer Coach, extensão do VS Code que lê logs locais das suas sessões de codificação com IA e os converte em insights acionáveis sobre seu fluxo de trabalho. Funciona com os principais harnesses e roda 100% na máquina local.

## Pontos-chave
- Extensão do VS Code que analisa logs de sessões de codificação assistida por IA e gera insights acionáveis de uso
- Compatível com múltiplos harnesses: Claude Code, Copilot, Cursor, Codex e Cline
- Todo o processamento é local, sem enviar dados para a nuvem
