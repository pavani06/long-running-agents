# Monid: OpenRouter para tools de agentes

**@shengkunye** · [2100330818958975088](https://x.com/shengkunye/status/2100330818958975088) · `announcement`

## Resumo
Anúncio de que o Monid foi open-sourced como camada unificada (análogo ao OpenRouter, mas para ferramentas) permitindo que agentes descubram, executem e paguem por 2.000 APIs em runtime via uma única conexão. Vale salvar como referência de infraestrutura emergente de descoberta e monetização dinâmica de tools.

## Pontos-chave
- Monid tornou-se open source, posicionando-se como 'o OpenRouter para agent tools'
- Agentes podem descobrir, executar e pagar por ferramentas em runtime, sem integração estática prévia
- Uma única conexão dá acesso a 2.000 APIs nas categorias: SEO, leads, redes sociais, busca, ecommerce, ações, geração de vídeo/imagem/música/3D e dados privados
- O modelo implica pagamento por uso de tools negociado dinamicamente pelo agente, não pelo desenvolvedor
