# MCP acessível via REPL para agentes

**@tobi** · [2100055404650573833](https://x.com/tobi/status/2100055404650573833) · `opinion`

## Resumo
Tobi argumenta que a utilidade dos MCPs para modelos depende de estarem acessíveis através de alguma forma de REPL; sem isso, bash e ferramentas de CLI acabam servindo como um REPL de facto para os agentes.

## Pontos-chave
- A utilidade dos MCPs por agentes é condicional: os modelos precisam poder invocá-los através de algum tipo de interface REPL.
- Quando não há acesso direto via REPL, bash e CLIs funcionam como substituto, atuando como a camada pela qual o modelo interage com as ferramentas.
