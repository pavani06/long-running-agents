# LoopX: orquestração cross-session de agentes

**@Xudong07452910** · [2085526335506592087](https://x.com/Xudong07452910/status/2085526335506592087) · `tool`

## Resumo
Apresenta o LoopX, projeto open-source voltado a problemas que surgem quando trabalho de agentes atravessa dias, múltiplas sessões e múltiplos agentes. Vale salvar como referência de ferramenta para coordenação e continuidade de tarefas longas entre agentes.

## Pontos-chave
- Agentes performam bem em tarefas de turno único, mas problemas reais começam quando o trabalho cruza múltiplos dias, sessões e agentes.
- Problemas típicos citados: objetivos mudam, evidências expiram, tarefas ficam sem dono e o scheduler continua queimando créditos.
- LoopX é open-source e se propõe a tratar especificamente essa classe de falhas de coordenação de longo prazo.
- Integra-se com agentes como Codex, Claude Code, Cursor e Pi.
