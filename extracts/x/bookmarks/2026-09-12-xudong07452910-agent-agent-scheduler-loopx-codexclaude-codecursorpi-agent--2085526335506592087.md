# Orquestração de agentes cross-session

**@Xudong07452910** · [2085526335506592087](https://x.com/Xudong07452910/status/2085526335506592087) · `announcement`

## Resumo
Aponta que agentes performam bem em tarefas single-turn, mas surgem problemas reais quando o trabalho atravessa dias, múltiplas sessões e múltiplos agentes (objetivos mudam, evidências expiram, tarefas órfãs, scheduler queimando quota). Apresenta o LoopX, projeto open-source dedicado a esses problemas, com integração a Codex, Claude Code, Cursor e Pi.
