# Claude plugin evals

**@trq212** · [2098531560643539440](https://x.com/trq212/status/2098531560643539440) · `announcement`

## Resumo
Anúncio de 'plugin evals' no Claude Code, recurso para verificar se skills/plugins continuam funcionando após novos lançamentos de modelo, via `claude plugin eval init`. Vale salvar como comando concreto para manter evals de plugins próprios.

## Pontos-chave
- Responde ao feedback de que é difícil saber se suas skills ainda funcionam com novas versões de modelo
- Uso: rodar `claude plugin eval init` dentro da pasta do plugin para inicializar os evals
