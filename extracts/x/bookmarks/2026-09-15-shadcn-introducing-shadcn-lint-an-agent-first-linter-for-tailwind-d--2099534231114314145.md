# shadcn/lint, linter agent-first para Tailwind

**@shadcn** · [2099534231114314145](https://x.com/shadcn/status/2099534231114314145) · `tool`

## Resumo
Anúncio do shadcn/lint, um linter 'agent-first' para design systems em Tailwind: o time define o que é permitido e, quando um agente quebra uma regra, o erro explica o que está errado e como corrigir usando os componentes, variantes e tema do próprio projeto. Vale salvar como padrão de guardrail com feedback acionável para agentes de código.

## Pontos-chave
- Regras centradas no design system: o time define o que agentes podem ou não gerar em Tailwind
- Erros são explicativos e didáticos: indicam a violação e o caminho de correção usando componentes/variantes/tema existentes
- Padrão de guardrail via mensagens de erro legíveis por LLM, tornando o linter um mecanismo de correção automática para agentes de coding
- Integra verificação de conformidade de UI ao loop de agentic coding em vez de depender só de review humano
