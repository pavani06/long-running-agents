## Resumo
Lance Martin adicionou o comando /claude-api prompt-audit à skill claude-api, executável no Claude Code, para detectar e corrigir anti-padrões comuns de prompting que degradam modelos de fronteira. Exemplo citado: 'rituais de verificação' como 'double-check your work'.

## Pontos-chave
- Novo comando /claude-api prompt-audit na skill claude-api, executado dentro do Claude Code
- Objetivo: corrigir anti-padrões de prompting que 'manietam' modelos de fronteira
- Um dos padrões alvo são os 'verification rituals' — instruções como 'double-check your work'
