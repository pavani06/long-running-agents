# Apple M5 Ultra vs Nvidia para IA

**@andrewchen** · [2099279190491353442](https://x.com/andrewchen/status/2099279190491353442) · `opinion`

## Resumo
Andrew Chen argumenta que rodar LLMs em hardware Apple esbarra em custo alto (~US$ 40k para o M5U de 512GB), no ecossistema de tuning incomparável da Nvidia e na defasagem de largura de banda de memória.

## Pontos-chave
- O M5 Ultra com 512GB deve custar cerca de US$ 40 mil, limitando o apelo de custo da Apple para LLMs locais
- A comunidade Nvidia é imbatível: cada modelo é intensamente otimizado/tunado para suas GPUs, algo que não existe para outras arquiteturas
- Persiste uma grande defasagem de memory bandwidth entre Apple Silicon e GPUs Nvidia, crítica para inferência de LLMs
