Início de uma thread com 10 avaliações de agentes para engenheiros de IA; a primeira é o 'golden set', um conjunto congelado de casos executado após qualquer mudança de prompt, modelo ou ferramenta para detectar melhorias ou regressões silenciosas. ## Pontos-chave
- Golden set é um conjunto fixo de casos de teste rodado após toda mudança de prompt, modelo ou ferramenta
- Funciona como baseline para verificar se o sistema melhorou ou quebrou silenciosamente
- OpenAI Evals permite construir benchmarks repetíveis e comparar resultados entre execuções
- Faz parte de uma série anunciada de 10 tipos de evals para agentes
