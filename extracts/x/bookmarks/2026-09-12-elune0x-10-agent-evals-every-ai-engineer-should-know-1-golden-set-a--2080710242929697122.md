# Golden sets para evals de agentes

**@elune0x** · [2080710242929697122](https://x.com/elune0x/status/2080710242929697122) · `thread`

## Resumo
Um 'golden set' é um conjunto congelado de casos executado após toda mudança de prompt, modelo ou ferramenta, servindo de baseline para detectar se o sistema melhorou ou quebrou silenciosamente. Vale salvar como técnica prática de regressão contínua, com OpenAI Evals citado para construir benchmarks repetíveis.
