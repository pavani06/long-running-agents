# Context engineering em agent harnesses

**@LangChain** · [2100235963339313648](https://x.com/LangChain/status/2100235963339313648) · `announcement`

## Resumo
LangChain argumenta que o maior desafio de um agent harness é o context engineering — que informação o agente recebe e quando — e que tarefas longas sobrecarregam a context window. O Deep Agents resolve isso nativamente com filesystems, subagents e skills.

## Pontos-chave
- Context engineering (qual informação o agente obtém, e em que momento) é apontado como o principal gargalo de um agent harness
- Quanto mais longa a tarefa, maior o risco de overload da context window
- Deep Agents traz mecanismos nativos de gestão de contexto: filesystem (armazenamento fora da janela), subagents (isolamento de contexto) e skills
