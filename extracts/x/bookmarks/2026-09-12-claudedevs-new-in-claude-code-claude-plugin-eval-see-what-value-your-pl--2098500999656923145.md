# Avaliação de plugins no Claude Code

**@ClaudeDevs** · [2098500999656923145](https://x.com/ClaudeDevs/status/2098500999656923145) · `announcement`

## Resumo
Novo comando `claude plugin eval` do Claude Code permite criar casos de teste, executar o plugin/skill contra eles, pontuar as execuções e rodar novamente sem o plugin para comparar diferenças. Útil para medir objetivamente o valor que um plugin ou skill agrega antes de publicar.
