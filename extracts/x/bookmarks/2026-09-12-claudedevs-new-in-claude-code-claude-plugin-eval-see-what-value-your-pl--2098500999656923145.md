# Claude Code plugin evals

**@ClaudeDevs** · [2098500999656923145](https://x.com/ClaudeDevs/status/2098500999656923145) · `announcement`

## Resumo
Anúncio do comando `claude plugin eval` no Claude Code, que permite medir o valor real de um plugin ou skill via casos de teste com comparação A/B contra execução sem o plugin.

## Pontos-chave
- Permite criar casos de teste e rodar o plugin ou skill contra esses casos
- Runs podem ser pontuados (scored) para avaliar qualidade das execuções
- Cada caso pode ser reexecutado sem o plugin ativo, permitindo comparar a diferença (baseline A/B) e verificar se o plugin agrega valor ou precisa de mais trabalho
