# Edição de Markdown fora do vault no Obsidian

**@obsdmd** · [2099930667769610431](https://x.com/obsdmd/status/2099930667769610431) · `announcement`

## Resumo
Obsidian 1.14.2 (early access) permite editar qualquer arquivo Markdown em seu local original, sem precisar movê-lo para dentro do vault. Elimina o atrito de copiar arquivos para editar e depois devolvê-los ao repositório ou pasta de origem.

## Pontos-chave
- Funciona para todos os formatos que o Obsidian suporta, não apenas .md básicos
- Remove o fluxo anterior de importar arquivos para o vault e reexportar após edição
- Facilita edição in-place de READMEs, docs de repositórios e notas em pastas externas
- Disponível apenas em early access na versão 1.14.2
