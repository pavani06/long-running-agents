# Docs e slides como artifacts no Claude Code

**@trq212** · [2100270818433643000](https://x.com/trq212/status/2100270818433643000) · `announcement`

## Resumo
Claude Code agora gera documentos e slides como artifacts compartilháveis, viabilizando colaboração da equipe — por exemplo, criar uma spec em doc, coletar feedback dos colegas e então pedir que o Claude implemente. Vale salvar como referência de workflow spec-first com revisão humana antes da implementação.

## Pontos-chave
- Docs e slides podem ser criados diretamente como artifacts dentro do Claude Code
- Artifacts são compartilháveis com o time, permitindo colaboração e feedback externo ao loop do agente
- Workflow sugerido: gerar spec como doc → revisão dos teammates → Claude implementa a spec aprovada
- Reforça o padrão de spec-driven development com checkpoint humano entre planejamento e execução
