# Mensageria entre sessões no Claude Code

**@ClaudeDevs** · [2085817074816070014](https://x.com/ClaudeDevs/status/2085817074816070014) · `announcement`

## Resumo
O Claude Code agora permite que sessões se comuniquem entre si: uma sessão pode enviar um resumo para outra, que retoma a tarefa no meio. Resolve o problema de ter que reexplicar contexto ao trocar de sessão.

## Pontos-chave
- Sessões do Claude Code podem agora enviar mensagens entre si, em vez de exigir re-explicação manual do contexto
- O que é transferido é um resumo — não o histórico completo nem os arquivos — preservando privacidade e tamanho do contexto
- A sessão destinatária pode retomar a tarefa de onde parou (mid-task handoff)
- O usuário instrui o Claude a fazer a transferência diretamente, sem precisar copiar/colar manualmente
