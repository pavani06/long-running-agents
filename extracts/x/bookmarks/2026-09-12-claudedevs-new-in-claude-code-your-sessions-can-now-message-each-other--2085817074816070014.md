## Resumo
Novo recurso do Claude Code permite que sessões troquem mensagens: uma sessão envia um resumo (não o histórico completo nem arquivos) e outra sessão retoma a tarefa no meio. Elimina a necessidade de reexplicar contexto ao alternar entre sessões.
