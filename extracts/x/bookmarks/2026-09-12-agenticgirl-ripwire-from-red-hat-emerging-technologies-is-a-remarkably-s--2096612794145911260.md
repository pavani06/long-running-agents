# contexto de repositório para coding agents

**@agenticgirl** · [2096612794145911260](https://x.com/agenticgirl/status/2096612794145911260) · `tool`

## Resumo
Ripwire, da Red Hat Emerging Technologies, fornece contexto de repositório a agentes de código sem embeddings, vector database, indexador LLM ou daemon — um binário C++23 zero-dependency que parseia 21 linguagens via Tree-sitter. Vale salvar como alternativa leve e determinística às soluções pesadas de indexação de contexto.

## Pontos-chave
- Elimina as dependências típicas de RAG para código: sem embeddings, sem banco vetorial, sem indexador movido a LLM e sem daemon em background
- Implementado como binário único em C++23 com zero dependências externas
- Cobre 21 linguagens de programação usando parsers Tree-sitter
- Projeto emergente da Red Hat Emerging Technologies focado em dar contexto de repo a coding agents
