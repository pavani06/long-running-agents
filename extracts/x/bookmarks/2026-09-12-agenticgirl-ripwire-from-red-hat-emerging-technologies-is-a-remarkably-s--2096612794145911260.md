# ripwire contexto de repositório para coding agents

**@agenticgirl** · [2096612794145911260](https://x.com/agenticgirl/status/2096612794145911260) · `announcement`

## Resumo
Ripwire, da Red Hat Emerging Technologies, é um binário C++23 zero-dependency que dá contexto de repositório a coding agents sem embeddings, vector DB, indexador LLM ou daemon, parseando 21 linguagens via Tree-sitter. Vale salvar como alternativa leve e determinística ao pipeline padrão de RAG para context-engineering de agentes de código.
