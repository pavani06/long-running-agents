# ferramenta de code review com LLM

**@ChrisShort** · [2098555200680218872](https://x.com/ChrisShort/status/2098555200680218872) · `tool`

## Resumo
Alibaba liberou como open source o open-code-review, arquitetura híbrida que combina pipelines determinísticos com LLM Agent, gerando comentários precisos em nível de linha. Inclui ruleset fine-tuned (NPE, thread-safety, XSS, SQL injection) e é compatível com APIs OpenAI e Anthropic — validado em escala na Alibaba.
