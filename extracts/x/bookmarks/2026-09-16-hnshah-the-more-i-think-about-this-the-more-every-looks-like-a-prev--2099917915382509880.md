# Desenvolvimento de produtos com software barato

**@hnshah** · [2099917915382509880](https://x.com/hnshah/status/2099917915382509880) · `opinion`

## Resumo
Observação de que a Every funciona como prévia do desenvolvimento de produtos quando software se torna barato: ferramentas nascem de necessidades internas e, se se espalham pela equipe, são transformadas em produtos para leitores. É um modelo relevante para pensar validação e product-led discovery em startups na era de criação de software por IA.

## Pontos-chave
- Produtos da Every (Cora, Sparkle, Spiral) começam como ferramentas que o próprio time precisa usar internamente
- O critério de productização é orgânico: se a ferramenta se espalha pela equipe, ela é colocada na frente dos leitores
- Esse fluxo interno→público sugere como o desenvolvimento de produto funciona quando o custo de software cai drasticamente
- O caso serve de modelo de validação pré-lançamento baseado em uso real, não em pesquisa de mercado
