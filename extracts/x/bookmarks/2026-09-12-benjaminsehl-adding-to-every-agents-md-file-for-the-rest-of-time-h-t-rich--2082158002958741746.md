# Simplified Technical English em AGENTS.md

**@benjaminsehl** · [2082158002958741746](https://x.com/benjaminsehl/status/2082158002958741746) · `opinion`

## Resumo
Sugere escrever arquivos AGENTS.md usando ASD-STE100 (Simplified Technical English), o inglês controlado criado para documentação aeroespacial, para reduzir ambiguidade nas instruções dadas a agentes de código.

## Pontos-chave
- ASD-STE100 é uma norma de inglês controlado (vocabulário e estruturas de frase restritos) originalmente criada para manuais de manutenção aeroespacial, onde ambiguidade custa caro
- Aplicar STE a AGENTS.md torna instruções para agentes de IA mais literais e menos sujeitas a interpretação errada
- A referência de Richard Penner explica o que é ASD-STE100 de forma auto-referencial, ou seja, escrita no próprio Simplified Technical English
