# Agentes resolvem benchmark NanoChat

**@hyperparticle** · [2099861544481731058](https://x.com/hyperparticle/status/2099861544481731058) · `announcement`

## Resumo
@hyperparticle relata que um enxame de agentes de IA bateu o SoTA no benchmark NanoChat do Karpathy em 3 dias, usando um harness próprio sobre um banco de dados em grafo para 'auto-autoresearch'. Vale salvar como evidência de harnesses iterativos que aprendem com erros superando abordagens tradicionais.

## Pontos-chave
- Um enxame (swarm) de agentes de IA superou o SoTA no benchmark NanoChat de Karpathy em 3 dias
- A equipe construiu um harness próprio sobre um banco de dados em grafo para automatizar pesquisa ('auto-autoresearch')
- Cada iteração aprende com os erros anteriores para fazer pesquisa melhor — um loop de melhoria contínua
- O processo gerou mais de 15.000 entradas documentadas durante os experimentos
