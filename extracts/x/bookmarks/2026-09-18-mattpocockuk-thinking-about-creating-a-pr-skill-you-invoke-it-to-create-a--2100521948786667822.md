# Skill de criação de PRs

**@mattpocockuk** · [2100521948786667822](https://x.com/mattpocockuk/status/2100521948786667822) · `announcement`

## Resumo
Matt Pocock propõe um '/pr skill' (comando/skill para agentes de código) que gera pull requests otimizados para revisão humana rápida, reaproveitando padrões de /show-me e /grill-with-docs e anexando evidências de que a mudança funciona. É um esboço de design útil para quem está construindo harness de coding agents com foco em revisão eficiente.

## Pontos-chave
- O objetivo central é minimizar o tempo e o esforço de revisão humana através da estrutura do PR gerado pelo agente
- Reutiliza as melhores partes do '/show-me' de Dex Horthy (demonstrar a mudança ao revisor)
- Usa a linguagem de domínio do projeto capturada por '/grill-with-docs' para consistência terminológica
- PRs devem incluir evidências visuais (imagens) de que a mudança funciona, não só descrição
