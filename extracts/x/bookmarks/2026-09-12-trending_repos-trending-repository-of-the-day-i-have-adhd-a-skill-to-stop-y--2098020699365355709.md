# Skill ADHD-friendly para agentes de código

**@trending_repos** · [2098020699365355709](https://x.com/trending_repos/status/2098020699365355709) · `tool`

## Resumo
Repositório trending 'i-have-adhd': skill/plugin para Claude Code que força saídas diretas do agente de código — ação primeiro, passos numerados, sem preâmbulos nem fechos. Vale salvar como referência de engenharia de output/instrução para coding agents, com 10 regras prontas para copiar em SKILL.md.

## Pontos-chave
- Define 10 regras de formato de resposta: liderar com a próxima ação, numerar tarefas multi-passo, terminar com um próximo passo concreto, suprimir tangentes e cap de 5 itens por lista.
- Regras de estado e clareza: reafirmar o estado a cada turno, estimativas de tempo específicas (minutos), erros tratados de forma objetiva, tornar vitórias visíveis.
- Zero ruído conversacional: sem preâmbulo, sem recapitulação, sem closers tipo 'Hope this helps!' — aplicável a qualquer agente, sem diagnóstico de TDAH necessário.
- Instalação e customização via Claude Code plugin marketplace; fork é simples: editar skills/i-have-adhd/SKILL.md e trocar a cópia upstream.
- Base conceitual adaptada de 'The Adult ADHD Tool Kit' (J. Russell Ramsay e Anthony L. Rostain), traduzida para como um LLM deve responder; licença MIT; 36.5k+ stars.
