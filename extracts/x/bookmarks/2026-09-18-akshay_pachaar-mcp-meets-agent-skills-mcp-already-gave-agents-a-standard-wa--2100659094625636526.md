# Descoberta de Agent Skills via MCP

**@akshay_pachaar** · [2100659094625636526](https://x.com/akshay_pachaar/status/2100659094625636526) · `announcement`

## Resumo
MCP (Model Context Protocol), que já padronizava a conexão de agentes a ferramentas, recursos e sistemas externos, agora também define um padrão para descobrir e carregar Agent Skills diretamente de servidores MCP. Vale salvar como marco de padronização do ecossistema de agentes, unificando tooling e skills num único protocolo.

## Pontos-chave
- MCP já fornecia forma padrão de conectar agentes a ferramentas, recursos e sistemas externos
- Agora o protocolo também padroniza descoberta e carregamento de Agent Skills hospedadas em servidores MCP
- Fluxo simplificado: conectar ao servidor MCP e descobrir skills disponíveis, eliminando integrações ad hoc para capacidades de agente
