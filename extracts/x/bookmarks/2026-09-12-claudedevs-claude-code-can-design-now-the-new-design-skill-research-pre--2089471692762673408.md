# Claude Code /design skill

**@ClaudeDevs** · [2089471692762673408](https://x.com/ClaudeDevs/status/2089471692762673408) · `announcement`

## Resumo
A Anthropic lançou o /design (research preview) no Claude Code, trazendo o workflow de artboards do Claude Design para CLI e Desktop, construído sobre artifacts. Permite gerar artboards editáveis de UI, escolher, ajustar e pedir que o Claude implemente.

## Pontos-chave
- Novo /design skill em research preview integra o artboard workflow do Claude Design no CLI e Desktop do Claude Code
- Construído sobre artifacts, gerando artboards editáveis para design de UI
- Fluxo: gerar variações de artboards, escolher uma, ajustar e então deixar o Claude implementar o código
- Reduz o ciclo design→implementação dentro da mesma ferramenta de coding agentic
