# Revisão de artefatos de contexto entre modelos

**@glaucia_lemos86** · [2096649629068624378](https://x.com/glaucia_lemos86/status/2096649629068624378) · `other`

## Resumo
Glaucia Lemos relata que, seguindo conselho de @pvncher, pediu ao modelo Astra para ler o artigo dele num projeto iniciado com o modelo Sol, e o modelo passou a identificar débitos técnicos nos artefatos de contexto do projeto e a atualizá-los automaticamente. Vale salvar como evidência de que auditoria de arquivos de contexto por um segundo modelo é uma técnica prática e eficaz.

## Pontos-chave
- Técnica de revisão cruzada: usar um modelo (Astra) para auditar artefatos de contexto produzidos no fluxo de trabalho iniciado por outro modelo (Sol)
- O modelo identificou 'débitos técnicos' nos artefatos de contexto do projeto — ou seja, context files também acumulam dívida como código e precisam de manutenção
- O modelo não só detectou os problemas como já atualizou os artefatos, agindo de forma agentic sobre a própria base de contexto
- A prática derivou de conselho de @pvncher de pedir ao modelo que lesse seu artigo como guia de processo
