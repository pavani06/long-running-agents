# pipeline de code review com agentes

**@0xDeliriumm** · [2081050632727793775](https://x.com/0xDeliriumm/status/2081050632727793775) · `announcement`

## Resumo
Boris Cherny (lead do Claude Code na Anthropic) publicou um pipeline em que um agente Claude é disparado ao abrir um PR, analisa e fecha 74% dos pull requests sem intervenção humana, atacando o gargalo de espera por review.

## Pontos-chave
- O pipeline fecha 74% dos PRs sem intervenção humana.
- Code review é apontado como o maior gargalo: desenvolvedores gastam mais tempo esperando reviews do que escrevendo código.
- Fluxo: PR aberto → agente Claude disparado → análise e fechamento automático.
