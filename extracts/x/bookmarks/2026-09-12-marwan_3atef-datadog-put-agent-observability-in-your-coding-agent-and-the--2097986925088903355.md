## Resumo
Datadog lançou Agent Observability via MCP toolsets (llmobs + core) que puxam traces de LLM em produção direto para Claude Code, Cursor, Codex e Gemini CLI, além de Pup CLI no shell e Agent Skills. Elimina o fluxo de tirar screenshots de traces e colar no Slack.
