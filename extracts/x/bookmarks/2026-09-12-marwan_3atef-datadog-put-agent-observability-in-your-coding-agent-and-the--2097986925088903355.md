# Datadog Agent Observability para coding agents

**@Marwan_3atef** · [2097986925088903355](https://x.com/Marwan_3atef/status/2097986925088903355) · `announcement`

## Resumo
Datadog integrou Agent Observability diretamente em coding agents via MCP toolsets (llmobs + core), permitindo consultar traces de LLM de produção dentro do Claude Code, Cursor, Codex ou Gemini CLI. O argumento central é eliminar o fluxo manual de tirar screenshots de traces e colar no Slack.

## Pontos-chave
- MCP toolsets llmobs + core puxam traces de produção LLM direto para o contexto do agente de código (Claude Code, Cursor, Codex, Gemini CLI)
- Pup CLI oferece o mesmo acesso a traces diretamente do shell
- Agent Skills funcionam como camada adicional sobre a integração
- Objetivo declarado: substituir o compartilhamento manual de screenshots de traces no Slack por consulta nativa
