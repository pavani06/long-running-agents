# NVIDIA open-sources SoL-Pi agent harness

**@MaxForAI** · [2098050525279478059](https://x.com/MaxForAI/status/2098050525279478059) · `announcement`

## Resumo
NVLabs (NVIDIA) open-sourced SoL-Pi (Scaling Auto-Research Loops for Efficient Agent Harnesses) under MIT license. Rather than a new harness from scratch, it is an efficiency enhancement layer built on top of Pi for auto-research agent loops.

## Pontos-chave
- SoL-Pi is open-sourced by NVLabs under MIT license
- It is not a new harness built from zero, but a harness efficiency enhancement layer based on Pi
- The project's focus is scaling auto-research loops for more efficient agent harnesses
- Part of NVIDIA AI's broader push into agent infrastructure
