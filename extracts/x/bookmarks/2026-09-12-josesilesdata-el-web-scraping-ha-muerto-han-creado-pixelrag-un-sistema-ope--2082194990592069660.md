# PixelRAG: web scraping visual

**@josesilesdata** · [2082194990592069660](https://x.com/josesilesdata/status/2082194990592069660) · `announcement`

## Resumo
Anúncio do PixelRAG, sistema open source que substitui o parsing de HTML por capturas de tela lidas diretamente por um modelo vision-language. Vale salvar como sinal da tendência de usar VLMs para extração de dados web sem depender da estrutura do DOM.

## Pontos-chave
- Abordagem alternativa ao scraping tradicional: em vez de converter HTML em texto, captura a página como imagem.
- Um modelo vision-language interpreta a resposta/conteúdo diretamente dos pixels, evitando quebras por mudanças de markup e parseadores frágeis.
- O projeto é open source, segundo o tweet.
