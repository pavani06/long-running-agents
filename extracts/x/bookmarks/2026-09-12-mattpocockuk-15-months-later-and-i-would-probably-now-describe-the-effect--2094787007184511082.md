# Documentação exemplar do Effect

**@mattpocockuk** · [2094787007184511082](https://x.com/mattpocockuk/status/2094787007184511082) · `opinion`

## Resumo
Matt Pocock classifica, após 15 meses, a documentação do Effect (TypeScript) como 'exemplar', destacando ótima introdução e progressive disclosure. Vale como referência de boas práticas para documentação de bibliotecas complexas.

## Pontos-chave
- Após 15 meses de uso, Pocock reavalia os docs do Effect como 'exemplary', antes criticáveis
- Estrutura elogiada: bem organizados, ótima introdução e progressive disclosure (revelar complexidade gradualmente)
- Definição conceitual destacada: 'An Effect is a value that fully describes a program' — o que a torna eficaz para onboarding
- Serve como benchmark para documentar bibliotecas com superfície de API grande e conceitos abstratos
