# Transições UI para agentes de código

**@jonathan_wilke** · [2098801944756154391](https://x.com/jonathan_wilke/status/2098801944756154391) · `resource`

## Resumo
Coleção de transições/animações essenciais para web apps, prontas para copiar e colar ou consumir via 'skill' por agentes de código. O argumento: num mundo de 'AI slop', pequenos detalhes de animação diferenciam o produto.

## Pontos-chave
- Biblioteca de transições UI padrão de produto: processamento de transações, sliders, validação de formulário, drag & drop, cartões de crédito e listas de tarefas com subtasks
- Feita para ser usada com agentes de código via skill, além do copy-paste manual
- Argumento central: com todos entregando UI genérica gerada por IA, microinterações bem-feitas são o que faz o produto se destacar
- Recomenda o curso de Emil Kowalski ('Invisible Details') como referência de craft em animação de interfaces
