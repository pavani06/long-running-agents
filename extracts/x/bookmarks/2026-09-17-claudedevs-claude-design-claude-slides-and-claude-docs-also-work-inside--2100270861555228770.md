# Apps Claude dentro do Claude Code

**@ClaudeDevs** · [2100270861555228770](https://x.com/ClaudeDevs/status/2100270861555228770) · `announcement`

## Resumo
Anthropic integrou Claude Design, Slides e Docs ao Claude Code, permitindo gerar decks de design review e mockups de UI ancorados nos arquivos e RFCs reais do repo. O output é editável, iterável na conversa e compartilhável por link.

## Pontos-chave
- Claude Design, Claude Slides e Claude Docs agora funcionam dentro do Claude Code
- É possível pedir um design review deck ou UI mockup apontando para arquivos e RFCs reais do repositório (repo como contexto)
- Resultado pode ser editado manualmente ou continuado iterativamente na conversa
- Entrega final é compartilhável via link
