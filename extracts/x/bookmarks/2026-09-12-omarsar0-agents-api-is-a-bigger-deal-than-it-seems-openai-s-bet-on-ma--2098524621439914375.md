# OpenAI Agents API e harness-as-a-service

**@omarsar0** · [2098524621439914375](https://x.com/omarsar0/status/2098524621439914375) · `opinion`

## Resumo
Opinião de que a Agents API da OpenAI é estratégica e que a aposta de open-source do harness do Codex pode viabilizar um mercado emergente de 'harness-as-a-service'. Construtores sérios já adotam o modelo para desbloquear novos tipos de serviços.

## Pontos-chave
- A Agents API da OpenAI tem importância estratégica maior do que o aparente
- A decisão de tornar o harness do Codex open-source pode gerar retorno significativo, catalisando um ecossistema em volta do harness
- O modelo 'harness-as-a-service' ainda não é mainstream, mas construtores avançados já o adotam
- Adotar o harness como serviço permite desbloquear tipos novos de serviços sobre agentes
