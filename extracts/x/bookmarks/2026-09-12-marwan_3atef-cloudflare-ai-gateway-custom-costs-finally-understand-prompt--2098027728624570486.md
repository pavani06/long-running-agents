# Custos de prompt caching no Cloudflare AI Gateway

**@Marwan_3atef** · [2098027728624570486](https://x.com/Marwan_3atef/status/2098027728624570486) · `announcement`

## Resumo
Cloudflare AI Gateway agora aceita per_cache_read_token / per_cache_write_token em cf-aig-custom-cost, refletindo tarifas negociadas de cache nas métricas em vez de cobrar todo token a preço cheio. Dica concreta de configuração para reduzir e monitorar custos reais de LLM.
