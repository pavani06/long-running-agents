# Arquitetura multi-agente do zero

**@realfxw** · [2097956088792396200](https://x.com/realfxw/status/2097956088792396200) · `resource`

## Resumo
Recomendação do repositório open-source designing-multiagent-systems de Victor Dibia, código companion do livro, que inclui o framework educacional PicoAgents construído do zero. Vale salvar como roteiro prático para dominar os fundamentos de sistemas multi-agente sem depender de frameworks caixa-preta.

## Pontos-chave
- Melhor forma de dominar arquitetura multi-agente é implementá-la do zero, não consumir frameworks abstratos
- PicoAgents é framework didático embutido no repo, sem dependência de frameworks black-box
- Cobertura progressiva: começa em fundamentos como Agent Loop e Tool Calling, avançando para tópicos superiores
