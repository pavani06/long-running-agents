# Podar configuração do Claude Code

**@rohanpaul_ai** · [2082695402953031825](https://x.com/rohanpaul_ai/status/2082695402953031825) · `opinion`

## Resumo
Boris Cherny, criador do Claude Code, recomenda deletar claude.md, skills e hooks a cada ~6 meses para reobservar o comportamento do modelo puro, pois o scaffolding acumulado fica obsoleto conforme os modelos melhoram.

## Pontos-chave
- Recomendação prática: a cada ~6 meses apagar claude.md, skills e hooks e observar o que o modelo faz sem eles
- Premissa: modelos (ex.: Opus 5) evoluem rápido, e workarounds antigos podem conflitar ou degradar o desempenho atual
- Implicação: manter configuração mínima e reavaliar periodicamente o scaffolding frente às capacidades novas do modelo
