# LLM-as-a-judge para avaliar agentes de código

**@zachlloydtweets** · [2100621254579433575](https://x.com/zachlloydtweets/status/2100621254579433575) · `resource`

## Resumo
Defende que, numa software factory, é preciso medir o desempenho de agentes de coding em vez de adivinhá-lo, propondo uma abordagem LLM-as-a-judge em que agentes avaliam e pontuam o trabalho de outros agentes.

## Pontos-chave
- Adivinhar a performance de coding agents é insustentável numa operação de software factory em escala; medição é pré-requisito para melhorar.
- A abordagem proposta usa LLM-as-a-judge: um agente avaliador grada e mede a saída/trabalho de outros agentes de forma automatizada.
- Vincula a prática de evals automatizados ao contexto de produção de software com agentes, não apenas a benchmarks offline.
