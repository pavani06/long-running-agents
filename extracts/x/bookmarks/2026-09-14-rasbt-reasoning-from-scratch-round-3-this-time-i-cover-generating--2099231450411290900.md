# Verificadores para avaliação e RLVR

**@rasbt** · [2099231450411290900](https://x.com/rasbt/status/2099231450411290900) · `resource`

## Resumo
Terceiro vídeo da série 'reasoning from scratch' de Sebastian Raschka sobre gerar um verificador para dois propósitos: (a) avaliar modelo base vs. melhorias futuras e (b) servir de base para treino com RLVR (reinforcement learning with verifiable rewards).

## Pontos-chave
- O verificador cumpre dupla função: medir se um modelo melhorou em relação ao base e fornecer a recompensa verificável no treino via RLVR
- RLVR depende de um verificador automático e auditável para atribuir recompensas durante o treinamento por reforço
- O vídeo cobre quatro abordagens para LLMs antes de entrar na geração do verificador, com timestamps para navegação
