# Agent harness APIs como integração

**@kevinwhinnery** · [2098444890602455431](https://x.com/kevinwhinnery/status/2098444890602455431) · `opinion`

## Resumo
Opinião de que a era do 'token pipe' burro (APIs de streaming bruto de tokens) está acabando e que harness de agentes será o novo ponto de integração para aplicações de IA. Vale salvar como tese sobre para onde caminha a camada de integração de apps de IA.

## Pontos-chave
- APIs de streaming de tokens puro ('dumb token pipe') deixarão de ser a superfície principal de integração em aplicações de IA
- Agent harness APIs — runtimes de nível mais alto que orquestram agentes — serão o novo ponto de integração padrão
