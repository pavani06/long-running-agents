# The best ChatGPT Prompt I've ever created - I spent 2 months curating this prompt to write prompts

## Tese
Um meta-prompt reutilizável estruturado no framework CRAFT (Context, Role, Action, Format, Target Audience) permite que o ChatGPT gere prompts detalhados e de alta qualidade com mínimo esforço do usuário.

## Conceitos-chave
- meta-prompt (prompt para criar prompts)
- framework CRAFT (Context, Role, Action, Format, Target Audience)
- designação de papel especialista (role prompting)
- definição de contexto no prompt
- especificação de formato de saída (ensaio, tabela, markdown, lista etc.)
- definição de público-alvo
- uso de exemplo de referência como guia (few-shot / exemplo tuning)
- elementos fill-in-the-blank com colchetes para personalização posterior
- instruções sequenciais em lista numerada
- solicitação proativa de informações faltantes pelo modelo
- execução do prompt gerado em novo chat (isolamento de contexto)

## Ferramentas & pessoas
**Ferramentas:** ChatGPT, ChatGPT Canvas, Gemini, DeepSeek, Claude

**Pessoas/orgs:** YouTube

## Claims acionáveis
- Estruture prompts com as cinco seções CRAFT (Context, Role, Action, Format, Target Audience) para obter respostas superiores à média
- Instrua o modelo a solicitar o tópico/tema caso não seja fornecido, evitando suposições incorretas
- Inclua um exemplo completo do prompt desejado dentro do meta-prompt para orientar o formato da saída gerada
- Peça que o prompt gerado contenha elementos fill-in-the-blank entre colchetes para o usuário popular conforme sua necessidade
- Use listas numeradas para manter instruções sequenciais e ordenadas no prompt
- Execute o prompt gerado em um novo chat para começar do zero e depois edite seletivamente trechos (ex.: estilo de parágrafos) antes de rodar
- Copiar e colar um meta-prompt curador elimina o esforço de escrever prompts longos manualmente a cada uso
- O autor alega (sem evidência) que frases como 'take a deep breath, one step at a time' melhoram o foco do modelo
- Instruir o modelo a escrever prompts que 'não deixam nada em questão' tende a gerar outputs mais detalhados
