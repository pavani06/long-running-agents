# How to Build PERFECT Looking Apps With Bolt.new (Easy Hack)

## Tese
Usar screenshots de templates profissionais de UI do Dribbble como referência visual nos prompts do bolt.new permite construir apps visualmente polidos em minutos, sem saber programar, desde que se especifique explicitamente que a funcionalidade difere da do template.

## Conceitos-chave
- prompt com referência visual (screenshot de UI como guia)
- especificação explícita de divergência entre estética e funcionalidade do template
- refinamento iterativo de prompts para corrigir layout e erros
- prototipagem rápida no-code/low-code
- loop de feedback via preview e correções incrementais
- deploy nativo dentro da ferramenta

## Ferramentas & pessoas
**Ferramentas:** bolt.new, Dribbble (dribbble.com), FocusFlow (app-exemplo de rastreamento de sessões de trabalho)

**Pessoas/orgs:** Brock (apresentador), Amanda (nome-placeholder da UI usada como exemplo), agência de desenvolvimento em bolt.new do apresentador (menção promocional)

## Claims acionáveis
- Busque templates de UI no Dribbble e faça screenshot dos que gostar para usar como referência visual ao promptar o bolt.new
- Ao enviar o screenshot, instrua explicitamente que a funcionalidade do seu app difere da do template, para evitar interfaces bonitas mas quebradas ou sem sentido
- Se o resultado ignorar o estilo pedido, reenvie o screenshot com instrução direta do tipo 'copie esta interface do screenshot'
- Reporte erros do preview ao assistente para que ele reescreva o código automaticamente
- Corrija problemas de layout com prompts curtos e específicos, como mover o timer para a própria linha para não ficar comprimido
- Itere seção por seção (ex.: reestilizar o histórico de sessões com base em outro screenshot) em vez de redescrever o app inteiro
- Use o botão de deploy (foguete azul) do bolt.new para publicar o app e obter um link compartilhável
- Um protótipo com UI praticamente finalizada pode ser construído em cerca de 8-10 minutos sem conhecimento técnico, restando ajustar funcionalidades
