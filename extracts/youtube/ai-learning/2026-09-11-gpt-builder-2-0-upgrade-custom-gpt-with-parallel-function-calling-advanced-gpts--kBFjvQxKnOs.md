# GPT Builder 2.0 🚀 UPGRADE Custom GPT with Parallel Function Calling 🤯 Advanced GPTs Tutorial

## Tese
O vídeo é um tutorial que demonstra como criar um Custom GPT no GPT Builder com múltiplas actions (clima via wttr.in e cotação de ações via API hospedada no Replit com API key) e testar a chamada paralela de funções em um único prompt.

## Conceitos-chave
- Custom GPTs (GPT Builder)
- Actions / function calling
- Parallel function calling
- OpenAPI schema
- Autenticação com API key (basic auth)
- Arquivos de conhecimento com embeddings automáticos
- Página de configuração (instruções, conversation starters, capabilities, privacy policy)

## Ferramentas & pessoas
**Ferramentas:** ChatGPT (chat.openai.com), GPT Builder, wttr.in, Replit, OpenAPI schema

**Pessoas/orgs:** OpenAI, Replit, Apple, YouTube (canal do apresentador)

## Claims acionáveis
- O GPT Builder agora suporta adicionar múltiplas actions e chamada paralela de funções em um Custom GPT
- As instruções definidas na aba Configure determinam o comportamento do Custom GPT
- Arquivos enviados na seção Knowledge são salvos automaticamente como embeddings, sem o usuário gerenciar o pipeline
- A action de clima usa o serviço wttr.in sem necessidade de API key, bastando passar a localização
- A action de stock price é hospedada no Replit e exige API key configurada como autenticação do tipo basic
- Um único prompt combinando duas intenções (preço da ação da Apple e clima em Londres) disparou ambas as actions em paralela com sucesso
- É necessário informar uma URL de privacy policy ao salvar cada action
