## Agentic Coding: Skills & Evals  (1)

O argumento central é que loops agentivos autônomos cegos (estilo 'Ralph') falham porque produzem PRs gigantes que ninguém lê; a alternativa é tratar o loop como um sistema de teoria de controle com quatro componentes explícitos — sensor, set point, controlador e atuador. O set point deve ser um estado final mensurável do codebase, definido antes de qualquer automação. O sensor deve rodar fora das configs que o agente consegue neutralizar: ast-grep como sensor language-agnostic, em vez de ESLint/TypeScript, que agentes silenciam com comentários inline. O controlador escolhe deterministicamente (a menor violação primeiro) para reduzir risco, reservando o LLM apenas para decisões que exigem julgamento, e um scan completo versionado no main permite detectar a cada PR se novas violações não migradas entraram.

> **Não-óbvio:** O insight não-óbvio é que o eval eficaz em agentic coding não pontua a saída do modelo, mas restringe onde o modelo tem discrição: um sensor isolado fora da superfície de ação do agente (imune a ser desabilitado por ele) mais uma ordenação determinística de violações transformam avaliação em arquitetura de controle, encolhendo o espaço de erro antes de qualquer julgamento do LLM.
